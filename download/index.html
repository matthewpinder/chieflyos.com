If your Mac shows a warning

This is normal. Apple has not put Chiefly on its list yet. You are allowed to open it anyway. Nothing here is a mistake you made.

The Mac cannot check this app.

Open Anyway

  1. Open the file you downloaded.

    Double-click it. It is the Chiefly file.

  2. Read the message. Then close it.

    It may say the Mac cannot check the app. That is the warning. Close it.

  3. Open System Settings.

    On an older Mac the same app is called System Preferences. Click Privacy & Security.

  4. Scroll down until you see Chiefly.

    Click Open Anyway.

  5. The Mac asks one more time.

    Click Open. Chiefly starts. You are done.

If no warning appears, Chiefly just opens. You are done.

If Windows shows a warning

This is normal. Windows does not know Chiefly yet. You can still run it. Nothing here is a mistake you made.

Windows protected your PC.

More info Run anyway

  1. Open the file you downloaded.

    Double-click it. It is the Chiefly file.

  2. A blue window may appear.

    It says Windows protected your PC. That is the warning.

  3. Click More info.

    It is a small link on that window. A new button appears.

  4. Click Run anyway.

    Chiefly starts. You are done.

If no warning appears, Chiefly just opens. You are done.
